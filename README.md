# Simple Node.js HTTP Server

This project is a simple Node.js server that serves static HTML pages (`index.html` and `about.html`).

## 🚀 Features
- Serves home (`/`) and about (`/about`) pages
- Logs missing file errors to `error.log`
- Returns a 404 page for unknown routes

## 🧠 How to Run

```bash
# Install Node.js if not installed
node -v

# Run the server
node server.js
